Applied AI Learning Hub Website

A maintainable public portfolio for courses, projects, roadmap progress, and reflective writing across the 2026–2028 master’s programme.

Status
In progress
Category
System Design for AI
Stack
HTML, CSS, JavaScript, JSON, GitHub Pages
Privacy
Privacy-safe

1. Project overview

This website is both a communication tool and a systems project: information architecture, accessible UI, content governance, and long-term maintainability.

2. Problem

A two-year learning journey produces fragmented notes and projects. Without a public structure, progress is hard to demonstrate and easy to lose.

3. Why the problem matters

Employers, mentors, and future collaborators benefit from clear evidence of learning. Writing also improves understanding.

4. Dataset

Not applicable. Content is authored documentation and metadata, not a modelling dataset.

5–6. Preparation and exploration

Content types were separated into JSON data files (courses, projects, skills, roadmap, resources, blog) and HTML templates for richer pages.

7. Methods

  • Static site architecture suitable for GitHub Pages
  • Progressive enhancement with vanilla JavaScript
  • Relative asset paths for project-site and user-site deployment
  • Explicit privacy and academic-integrity rules

8–10. Selection, metrics, and results

Success is measured by clarity, maintainability, accessibility, and honesty of status labels — not vanity metrics. The first milestone delivers a usable multi-page hub with data-driven catalogues.

11. Visualisations

No model charts yet. UI relies on typography, status badges, and structured cards rather than decorative AI imagery.

12–14. Errors, limitations, and ethics

Risks include accidental publication of private material and overclaiming skills. Mitigations include checklists, placeholders for unverified links, and careful status vocabulary.

15. Lessons learned

Central JSON files reduce duplication. Honest “upcoming/planned” labels build more trust than empty completion claims.

16. Future improvements

  • Additional course and project case studies
  • More learning notes
  • Optional migration to Astro/Next later if needed
  • Custom domain when chosen
