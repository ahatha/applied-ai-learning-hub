Lesson 3: SAT Solving and First-Order Logic

How satisfiability methods search for models of a propositional knowledge base, and how first-order logic describes objects and relations that propositional logic cannot express compactly.

Entailment · Satisfiability · CNF · Resolution · Conditioning · Scheduling · Predicates · Quantifiers
01

From entailment to SAT solving

In the previous lesson, entailment was defined by checking all models that satisfy a knowledge base. That definition gives a direct way to test a conclusion, but the number of assignments grows exponentially: with n Boolean variables there are 2n possible assignments.

A satisfiability (SAT) problem asks whether there is at least one truth assignment that makes a Boolean formula true. SAT gives a useful way to test entailment by contradiction:

KB ⊨ α iff KB ∧ ¬α is UNSAT

If KB ∧ ¬α has a satisfying assignment, that assignment is a counterexample to the entailment. If no such assignment exists, the knowledge base cannot be true while α is false, so it entails α.

Keep the two questions distinct: “Is this formula satisfiable?” asks whether at least one model makes it true. “Does KB entail α?” asks whether every model of KB makes α true. Entailment can be reduced to a SAT test by looking for a counterexample.

02

Conjunctive normal form

The notes present conversion to conjunctive normal form (CNF) as the setup for SAT solving. CNF is a conjunction (AND) of clauses, where each clause is a disjunction (OR) of literals. A literal is a variable or its negation.

(X₁ ∨ ¬X₂) ∧ (X₂ ∨ X₃) ∧ (¬X₁ ∨ X₃)

This is CNF: three clauses are joined by AND; the literals inside each clause are joined by OR. A unit clause contains just one literal, such as X₁ or ¬X₃.

CNF is useful because resolution and conditioning can operate clause by clause. The formulas in this lesson are already in CNF; the main focus here is how the two search methods use that representation.

Converting a formula by equivalence

The lecture connects this step with the equivalence rules from the previous lesson. For example, eliminate the biconditional, then rewrite each implication:

P ↔ M
≡ (P → M) ∧ (M → P)
≡ (¬P ∨ M) ∧ (¬M ∨ P)

The final expression is in CNF: it is an AND of two OR clauses. Each rewrite preserves the formula’s meaning.

03

SAT solving by resolution

Resolution combines two clauses that contain opposite forms of the same variable. If one clause contains Y and another contains ¬Y, resolve on Y and keep the remaining literals:

(X ∨ Y) ∧ (Z ∨ ¬Y) ⟹ (X ∨ Z)

Why is the resolvent justified? If both parent clauses are true, then either X is true or Y must be true; and either Z is true or Y must be false. In either case, at least one of X or Z must be true. The resolvent is therefore a consequence of its parent clauses.

Refuting an inconsistent clause set

The handwritten example lists these clauses:

C₁: (X₁ ∨ X₂) C₂: (¬X₁ ∨ X₃)
C₃: ¬X₂ C₄: ¬X₃
C₅: X₁ C₆: X₃

The handwritten resolution diagram shows these derived clauses:

  1. Resolve C₁, (X₁ ∨ X₂), with C₃, ¬X₂, on X₂. The result is X₁ (also listed as C₅).
  2. Resolve C₂, (¬X₁ ∨ X₃), with C₅, X₁, on X₁. The result is X₃ (also listed as C₆).
  3. Resolve C₆, X₃, with C₄, ¬X₃. The result is the empty clause, written □.
(X₁ ∨ X₂), ¬X₂ ⟹ X₁
(¬X₁ ∨ X₃), X₁ ⟹ X₃
X₃, ¬X₃ ⟹ □

Because the clauses lead to a contradiction, no assignment satisfies all of them. The clause set is UNSAT. In a proof by refutation for entailment, the set being refuted is KB ∧ ¬α.

Unit propagation

A unit clause contains one literal, such as X₁. It forces that literal to be true in any satisfying assignment. Substitute that value into the other clauses: clauses made true can be removed, and the opposite literal can be removed from clauses that remain. Repeating this process is called unit propagation. In the resolution example, the unit clauses let us simplify the clauses until a contradiction is reached.

04

SAT solving by conditioning

Conditioning chooses a variable, assigns it a truth value, and simplifies the formula using that assignment. A true clause is removed; within any remaining clause, a false literal is removed. The solver then checks whether the simplified formula is satisfiable.

  1. Choose a variable, for example X₁.
  2. Try X₁ = TRUE and simplify the formula.
  3. Try X₁ = FALSE and simplify the formula.
  4. Continue searching in the resulting branches until a satisfying assignment is found or every branch has failed.

A formula is SAT if at least one branch leads to a satisfying assignment. It is UNSAT only if both truth-value branches (and all later branches) fail.

Why SAT complexity matters

The lecture notes that the number of variables and the size of each clause affect how difficult the search can become. The special case 2-SAT, where each clause has at most two literals, can be solved in polynomial time. General 3-SAT is NP-complete. Despite the worst-case difficulty, practical SAT solvers can handle large real-world instances; the lecturer mentions examples with thousands of variables, while actual performance depends on the structure of the formula.

05

Conditioning example

Consider the CNF formula from the notes:

F = (X₁ ∨ ¬X₂) ∧ (X₂ ∨ X₃)

Branch 1: set X₁ = TRUE

The first clause is true, so it can be removed. The second clause remains:

(TRUE ∨ ¬X₂) ∧ (X₂ ∨ X₃)
TRUE ∧ (X₂ ∨ X₃)

Choose, for example, X₂ = TRUE. Then the remaining clause is true, so one satisfying assignment is X₁ = TRUE, X₂ = TRUE (with either value for X₃). This is enough to establish that F is SAT.

Branch 2: set X₁ = FALSE

The first clause simplifies to ¬X₂; the second remains:

¬X₂ ∧ (X₂ ∨ X₃)

The unit clause forces X₂ = FALSE. Then the second clause requires X₃ = TRUE. So this branch is also SAT, with assignment X₁ = FALSE, X₂ = FALSE, X₃ = TRUE.

The example shows how a truth assignment simplifies a larger formula into smaller constraints. A unit clause can immediately force a variable’s value.

06

Using SAT to represent a scheduling problem

SAT can encode planning and scheduling constraints. The lecture discusses assigning trucks to customers and scheduling university classes into time slots. For the truck example, let Xt,c mean “truck t is scheduled to serve customer c.” A proposed schedule is represented by assigning true or false to these variables.

To express that two different trucks must not both serve the same customer, add a clause for each pair of trucks:

For each customer c and distinct trucks t₁, t₂:
¬Xt₁,c ∨ ¬Xt₂,c

This clause rules out the assignment where both truck-to-customer variables are true. A complete scheduling model would also need clauses for the other requirements—for example, whether each customer must be served, truck capacity, availability and time conflicts. Each valid schedule then corresponds to a satisfying assignment of the encoded constraints.

Modeling principle: first define what each Boolean variable means; then translate each requirement into a logical constraint. The SAT solver only checks the formula you give it, so missing or incorrect constraints produce misleading schedules.

07

From propositional logic to first-order logic

Propositional logic represents complete statements as indivisible true-or-false symbols. This is enough for small, fixed worlds, but it becomes repetitive when the world contains many objects and relationships. First-order logic (FOL) adds objects, predicates and quantifiers, allowing one formula to describe patterns across many objects.

RepresentationExampleWhat it expresses
Propositional logicOnVaseTableA named fact: the vase is on the table.
First-order logicOn(Vase, Table)A relation between named objects.
First-order logic with a variableOn(x, Table)A relation involving an object selected by variable x.

To connect a physical world with a logical description, decide which objects are in the domain and what each predicate means. For example, the domain might contain a table, a vase, a ball and the floor. The predicate On(x, y) is true when object x is on object y, under the chosen interpretation.

A predicate is interpreted as a function from its object arguments to a truth value. This notation does not mean every physical property is automatically represented: the domain, predicates and their meanings must be specified so that formulas have a clear interpretation.

08

Predicates and quantifiers

A predicate describes a property or relation and evaluates to true or false for the objects supplied to it. For instance, On(Object, Table) is true when that object is on the table.

SymbolNameMeaningExample
∀Universal quantifierFor every object in the specified domain.∀x On(x, Table): every object in the domain is on the table.
∃Existential quantifierThere is at least one object in the specified domain.∃x On(x, Table): at least one object is on the table.

The variable’s domain matters. If x ranges over all objects, ∀x On(x, Table) makes a claim about every one of them. If it ranges only over selected objects, the claim applies only to that subset.

Negation can be moved across a quantifier by switching the quantifier and negating the formula inside:

¬∀x φ(x) ≡ ∃x ¬φ(x)
¬∃x φ(x) ≡ ∀x ¬φ(x)

“It is not true that every object has a property” means “there is at least one object that does not have the property.” “There does not exist an object with a property” means “every object lacks that property.”

09

Worked transformation of a quantified formula

Use the predicate meanings On(x, Table), On(x, Floor) and Touch(x, y). Start with the formula from the notes:

¬∀i [ On(i, Table) → ∃j (On(j, Floor) ∧ ¬Touch(i, j)) ]

Read the outer negation first: it says that it is not the case that every object i on the table satisfies the bracketed condition. Apply ¬∀i φ ≡ ∃i ¬φ:

∃i ¬[ On(i, Table) → ∃j (On(j, Floor) ∧ ¬Touch(i, j)) ]

For an implication, ¬(A → B) ≡ A ∧ ¬B. Here A is On(i, Table) and B is the existential statement:

∃i [ On(i, Table) ∧ ¬∃j (On(j, Floor) ∧ ¬Touch(i, j)) ]

Now move the negation through the existential quantifier using ¬∃j ψ ≡ ∀j ¬ψ, then apply De Morgan’s law:

∃i [ On(i, Table) ∧ ∀j ¬(On(j, Floor) ∧ ¬Touch(i, j)) ]
≡ ∃i [ On(i, Table) ∧ ∀j (¬On(j, Floor) ∨ Touch(i, j)) ]

The final formula means: there is an object on the table that touches every object on the floor. For each j, either j is not on the floor, or it touches the selected table object.

Check the scope: ∃i chooses one object on the table. The ∀j then checks every object in the domain, while the disjunction restricts the touching requirement to objects that are on the floor.

10

Key ideas

  • SAT asks whether a formula has at least one satisfying truth assignment.
  • To test KB ⊨ α, test whether KB ∧ ¬α is unsatisfiable.
  • CNF is an AND of clauses; each clause is an OR of literals.
  • Resolution combines clauses with complementary literals; deriving the empty clause shows contradiction.
  • Conditioning assigns a variable and simplifies the remaining formula, exploring alternative branches.
  • SAT can encode real constraints such as assigning trucks to customers, once variables and requirements are defined precisely.
  • First-order logic describes objects and relations with predicates, variables and quantifiers.
  • Negating a universal quantifier produces an existential quantifier, and negating an existential produces a universal quantifier.

Good practice for formula transformations: name the formula parts, apply one equivalence at a time, preserve quantifier scope, and read the final expression back in ordinary language to check that it still matches the original meaning. The lecturer notes that the result is an unusual or nonsensical fact about the world; the point is practising the transformation.
