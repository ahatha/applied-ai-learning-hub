# Contributing

This is primarily a personal learning portfolio. External contributions are welcome for clear fixes (broken links, accessibility, typos), but content direction remains with the site owner.

## How to contribute

1. Open an issue describing the change.
2. Fork the repository and create a focused branch.
3. Keep diffs small and avoid unrelated refactors.
4. Run through [PRIVACY_CHECKLIST.md](PRIVACY_CHECKLIST.md) and [ACADEMIC_INTEGRITY.md](ACADEMIC_INTEGRITY.md).
5. Open a pull request with a short summary and test notes.

## Content rules

- Do not invent grades, results, certifications, or endorsements
- Do not add unverified official university links
- Do not include private or confidential information
- Prefer updating JSON data files over duplicating content in multiple HTML pages

## Local checks

- Open home explorer, a course hub, and 404 via a static server
- Confirm light/dark theme toggle
- Confirm mobile navigation open/close (Escape and outside click)
- Confirm programme explorer keyboard selection (Tab, Enter/Space, Escape)
